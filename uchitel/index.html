Группы · что открыто ученикам
Чтобы открывать уроки отсюда, нужен ключ GitHub (один раз на этом устройстве).
  1. Откройте github.com → новый ключ (войдите в свой GitHub).
  2. Название — любое, например «Сайт таджвида». Срок — 1 год.
  3. Repository access → Only select repositories → detskiy-tajweed.
  4. Permissions → Repository permissions → Contents: Read and write.
  5. Generate token → скопируйте ключ и вставьте сюда.
Ключ хранится только в этом браузере и даёт доступ только к этому сайту.
