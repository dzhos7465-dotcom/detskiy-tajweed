# Домашние тренажёры (один ребёнок)

Сборка: `python3 tools/build_doma.py <тема>/index.html tools/home_<тема>.js <тема>/doma/index.html`

- Данные (RULES, ORDER, info, MAP, R2…, AYAT) берутся из групповой игры темы без изменений.
- `home_<тема>.js` — только раунды и подписи для ребёнка (обращение на «ты»).
- Шаблон `doma_src.html`: телефон / планшет / компьютер, имя ребёнка (только на устройстве),
  звёзды, перемешивание, работа над ошибками, продолжение с места остановки.
