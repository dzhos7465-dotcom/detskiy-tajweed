# Домашние тренажёры (один ребёнок)

Сборка: `python3 tools/build_doma.py <тема>/index.html tools/home_<тема>.js <тема>/doma/index.html`

- Данные (RULES, ORDER, info, MAP, R2…, AYAT) берутся из групповой игры темы без изменений.
- `home_<тема>.js` — только раунды и подписи для ребёнка (обращение на «ты»).
- Шаблон `doma_src.html`: телефон / планшет / компьютер, имя ребёнка (только на устройстве),
  звёзды, перемешивание, работа над ошибками, продолжение с места остановки.
- Готовы: мим (`home_mim.js`), нун (`home_nun.js`), мадд (`home_madd.js`). После правки шаблона пересобрать все три.

## Превью ссылок (Open Graph)
Картинка и описание, которые видны, когда ссылку присылают в WhatsApp или Telegram.
- `og_pages.py` — список страниц: картинка, заголовок, описание, плашка, арабский знак, цвет.
- `og_make.py` — рисует картинки 1200×630 в `assets/og/` (нужны playwright, Chrome, Pillow, шрифты @fontsource/nunito).
- `og_apply.py` — вписывает метатеги в страницы (между `<!-- og -->` и `<!-- /og -->`, повторный запуск ничего не дублирует).
**После любой пересборки страницы (игры, домашние тренажёры) запустить `python3 tools/og_apply.py`.**
Новая страница — добавить строку в `og_pages.py`, затем `og_make.py` и `og_apply.py`.
