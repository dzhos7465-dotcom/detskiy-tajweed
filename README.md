# detskiy-tajweed
Детский курс таджвида — тренажёры и материалы

## Сайт курса (с 17.11.2026)
- Главная: две двери (нулевой / первый курс), тренажёры, вход «Для учителя» (групповые игры).
- Список уроков и адреса — `assets/lessons.js`. Урок открыт, только если у него вписан `slug`.
  Папка урока: `nulevoy/<номер>-<6 случайных знаков>/` — `index.html` (копия страницы урока 1),
  `prezentaciya.html`, `chitaem-doma.png`; видео — id YouTube в поле `video`.
- Имя ребёнка и отметки шагов хранятся только в браузере (localStorage `dt_name`, `dt_progress`).
- Старые адреса тренажёров (/nun/, /mim/, /mim/doma/, /madd/) не менялись.
